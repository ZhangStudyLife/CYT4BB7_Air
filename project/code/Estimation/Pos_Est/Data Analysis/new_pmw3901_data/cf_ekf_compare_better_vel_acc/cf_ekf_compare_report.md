## 结论

- 互补滤波平均峰值偏差: 23.0761 cm/s，EKF 平均峰值偏差: 42.6742 cm/s。
- 互补滤波平均恢复时间: 0.6272 s，EKF 平均恢复时间: 0.0776 s。
- 本轮回放优先关注低纹理退化下的可恢复性，不将 EKF 直接上机，只保留为离线对比基线。
