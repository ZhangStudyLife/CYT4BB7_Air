## 机载落地建议

- 纯按得分最优，`w_flow_v=4.5` 的确更强，但考虑实飞泛化与控制侧保守性，机载建议先落在更稳妥的保守候选。
- 推荐机载参数改为：`w_flow_v=4.0`、`w_acc_bias=0.005`、`innov_gate=130 cm/s`、`dead_max_s=0.20 s`、`w_res_v=1.0`。
- 这组保守候选相对当前参数回放结果：`flow_valid` 由约 92.37% 提升到约 98.40%，最长连续失效由 1.88s 缩短到约 0.92s，创新 RMS 由约 32.03 cm/s 降到约 24.17 cm/s，前向融合慢偏移从约 -10.23 cm/s 收敛到约 -2.94 cm/s。
- 本轮数据下，SQUAL 与高度门控都不是主要问题，不建议优先调整 `SQUAL_HIGH/LOW` 或高度阈值；主要问题是创新门控过于容易把慢偏移放大成失效。

## 建议的下一轮验证

- 继续采集至少两类日志：一类为稳悬停，一类为小角度前后/左右拨杆后回中。
- 下一轮重点观察 `I8/I9` 创新是否仍存在单轴长期偏置；若前向仍有系统性负偏，再考虑进一步下调 `w_acc_bias` 到 0.003 或引入更明确的加速度零偏冻结逻辑。
