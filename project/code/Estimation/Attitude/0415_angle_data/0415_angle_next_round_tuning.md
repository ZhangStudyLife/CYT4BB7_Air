# 0415 角度环下一轮试飞建议

## 1. 先把结论钉死

这 5 组手动小打杆日志，只能回答角度环问题，和速度环无关。

基于 `04151231 / 04151238 / 04151250 / 04151324 / 04151329` 的相位、拟合、频域对比，当前硬结论如下：

1. `KP=7` 比 `KP=5` 明显更跟手，两轴都成立。
2. `Roll(X)` 上，`KI=0.1` 和 `KD=0.1` 都没有净正收益。
3. `Pitch(Y)` 上，`KI=0.1` 有小幅正收益；`KD=0.1` 只在中频局部有收益。
4. `KI+KD` 一起上，没有叠加出更好效果，反而把收益吃掉了。
5. 所以下一轮不该再用“X/Y 同参 + KI/KD 一起堆”的方式试。

一句话总结就是：

- `Roll` 先靠更高一点的 `P` 去拿相位，不要急着加 `I/D`。
- `Pitch` 可以在更高一点 `P` 的基础上，保留一丁点 `I`，但先别再叠 `D`。

---

## 2. 参数分析建议

### 2.1 Roll 轴

从现有 5 组日志看，`Roll` 的优先级是：

1. 先把 `KP` 从 `5` 往回抬。
2. `KI` 先保持 `0`。
3. `KD` 先保持 `0`。

原因很直接：

- `KP=5 -> 7` 时，`0.4~0.6Hz` 和 `0.7~1.0Hz` 相位都明显改善。
- `KI=0.1` 在 Roll 上只有很小幅值，而且经常被 `iterm_relax` 压小，实际贡献不够。
- `KD=0.1` 在 Roll 上更像低频拖相位，不像真正在帮你追目标。

所以 Roll 现在不该搞复杂，先回到“纯 P 主导”的路子。

### 2.2 Pitch 轴

从现有日志看，`Pitch` 比 `Roll` 更难伺候，但它和 `Roll` 不一样：

- `KI=0.1` 单独打开时，`Pitch` 的相位确实改善了。
- `KD=0.1` 单独打开时，中频有改善，但低频没有稳定收益。
- `KI+KD` 一起上以后，整体又变回去了。

所以 Pitch 的优先级应该是：

1. `KP` 先往上抬。
2. `KI` 留一个很小的值。
3. `KD` 暂时拿掉，避免把归因搞脏。

## 3. 下一轮试飞的主参数建议

如果你下一轮只想飞一组，建议直接上下面这一组：

| 轴 | `KP` | `KI` | `KD` | 说明 |
| --- | ---: | ---: | ---: | --- |
| Roll | `6.2` | `0.00` | `0.00` | 回收 `KP=7` 的相位优势，但不一步顶满到 `7` |
| Pitch | `6.0` | `0.08` | `0.00` | 先吃到一部分 `P` 改善，再保留一点点 `I` 的低频补偿 |

其他角度环参数先不动：

- `roll_angle_kff = 0`
- `pitch_angle_kff = 0`
- `roll_angle_i_limit = 80`
- `pitch_angle_i_limit = 80`
- `roll_angle_d_lpf = 15`
- `pitch_angle_d_lpf = 15`

这组参数的设计逻辑是：

1. Roll 先纯 P，避免 `KI/KD` 干扰判断。
2. Pitch 保留小 `I`，因为现有日志已经给出了正向证据。
3. 两轴都先把 `KD` 拿掉，因为这轮重点不是“阻尼够不够”，而是“相位能不能先回来”。

## 4. 如果你愿意按科学整定飞 3 组

如果你愿意下一轮连续飞 3 组，而不是只飞 1 组，那就按下面顺序来，归因最干净。

### 第 1 组：纯 P 回中

| 轴 | `KP` | `KI` | `KD` |
| --- | ---: | ---: | ---: |
| Roll | `6.0` | `0.00` | `0.00` |
| Pitch | `6.0` | `0.00` | `0.00` |

目的：

- 先验证 `KP=5 -> 6` 是否稳定把两轴相位往回拉。
- 这一组最干净，因为没有 `I/D` 干扰。

判据：

- 如果两轴都明显比 `KP=5` 跟手，而且没有新增来回摆，那说明方向对。

### 第 2 组：只给 Pitch 一点 I

| 轴 | `KP` | `KI` | `KD` |
| --- | ---: | ---: | ---: |
| Roll | `6.0` | `0.00` | `0.00` |
| Pitch | `6.0` | `0.08` | `0.00` |

目的：

- 只验证 `Pitch` 的小 `I` 是否继续带来低频和中频跟随改善。

判据：

- 如果 Pitch 的回中和小角度跟随更自然，说明 `KI` 该留。
- 如果开始出现低频拖泥带水或慢回摆，说明 `KI=0.08` 已经偏多，应退到 `0.05~0.06`。

### 第 3 组：只抬 Roll 的 P

| 轴 | `KP` | `KI` | `KD` |
| --- | ---: | ---: | ---: |
| Roll | `6.5` | `0.00` | `0.00` |
| Pitch | `6.0` | `0.08` | `0.00` |

目的：

- 只看 Roll 在 `KP=6.0 -> 6.5` 时，相位收益是否继续存在。

判据：

- 如果 Roll 明显更跟手但没有细碎来回摆，后面可以继续逼近 `6.5~6.8`。
- 如果已经开始出现小抖、小回摆，那 Roll 的甜点更像 `6.0~6.3`。

## 5. 不建议下一轮这么飞

下面这些方向，基于当前 5 组日志，我不建议继续：

### 5.1 Roll 再加 `KI`

不建议：

- `roll_angle_ki = 0.1`

原因：

- 现有证据不支持它对 Roll 有正向净收益。

### 5.2 Roll 再加 `KD`

不建议：

- `roll_angle_kd = 0.1`

原因：

- 它没有把 Roll 的低频和中频相位救回来。

### 5.3 Pitch 同时加 `KI + KD`

不建议：

- `pitch_angle_ki = 0.1`
- `pitch_angle_kd = 0.1`

原因：

- 单独看都像有点用，但叠起来之后效果反而没了。

### 5.4 两轴继续死板同参

不建议：

- `roll_angle_* == pitch_angle_*` 继续完全相同

原因：

- 现有日志已经证明 `Pitch` 和 `Roll` 不是同一类脾气。

---

## 6. 下一轮日志怎么飞才科学

为了让下一轮结论干净，动作建议固定：

1. 每组都飞同样的高度区间和同样电缆状态。
2. 每组先悬停 5 秒，再做小幅 `±3° ~ ±8°` 手动打杆。
3. 每个方向至少给 4~6 次对称小阶跃。
4. 不要中途改太多别的参数。

重点看这 4 件事：

1. 目标角度变化后，测量角度有没有更快贴上去。
2. 回中时有没有新增的低频摆动。
3. `roll_gyro_target / pitch_gyro_target` 有没有出现明显更碎的高频抖动。
4. `pitch` 是否继续明显比 `roll` 更肉或更吵。

---

## 7. 最终建议

如果你只飞一组，我建议：

```c
params->roll_angle_kp = 6.2f;
params->roll_angle_ki = 0.0f;
params->roll_angle_kd = 0.0f;

params->pitch_angle_kp = 6.0f;
params->pitch_angle_ki = 0.08f;
params->pitch_angle_kd = 0.0f;
```

如果你愿意按科学整定飞 3 组，就按：

1. `6.0/0/0 + 6.0/0/0`
2. `6.0/0/0 + 6.0/0.08/0`
3. `6.5/0/0 + 6.0/0.08/0`

这套路径的好处是：

- 每一步归因都干净。
- 先把 `P` 的相位拿回来。
- 只在有证据的轴上给一点 `I`。
- 不让 `KD` 提前把判断搞乱。
