# 水平加速度滤波候选筛选报告

## 约束

- 5Hz 幅值衰减不超过 3dB。
- 5Hz 等效群时延不超过 20ms。
- 综合评分 = 0.45*高频残余比 + 0.35*速度新息 RMS + 0.20*群时延归一化。

## 最优候选

- 候选: `Notch85Q3+LPF15`
- 5Hz 衰减: -0.052 dB
- 5Hz 群时延: 16.681 ms
- 右向高频残余比: 0.0002
- 前向高频残余比: 0.0002
- 右向速度新息 RMS: 46.7799 cm/s
- 前向速度新息 RMS: 79.3487 cm/s
