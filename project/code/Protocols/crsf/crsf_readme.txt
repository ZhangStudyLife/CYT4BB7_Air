CRSF（ELRS）模块说明

1. 模块作用
- 本模块用于接收 CRSF 遥控数据，并输出 `CRSF_CH[]` 原始通道值与 `CRSF_STD[]` 标准化结果。
- 本模块同时支持以 25Hz 向接收机回传姿态数据。
- 当前实现采用轮询硬件 FIFO 的方式读取串口数据，不依赖串口接收中断驱动业务逻辑。

2. 当前硬件配置
- 串口号：`UART_4`
- RX 引脚：`P14_0`
- TX 引脚：`P14_1`
- 波特率：`420000`
- 底层 SCB 映射：`SCB2`
- 链路超时定时器：`TC_TIME2_CH0`
- 失联判定阈值：`100000us`

3. 与代码对应的关键实现
- 初始化函数：`crsf_init()`
- 轮询更新函数：`CRSF_Update_100HZ()`
- 姿态回传函数：`crsf_send_50hz()`
- 原始通道缓存：`CRSF_CH[10]`
- 标准化通道缓存：`CRSF_STD[10]`
- 最近一次有效更新时刻：`CRSF_LAST_UPDATE_TIME`
- 链路状态：`CRSF_LINK_UP`

4. 初始化与调度方式
- 系统启动时调用一次 `crsf_init()`。
- `crsf_init()` 内部完成：
- 初始化 `UART4`
- 关闭库层串口接收中断业务模式：`uart_rx_interrupt(UART_4, 0)`
- 初始化并启动 `TC_TIME2_CH0`
- 周期任务中每 `10ms` 调用一次 `CRSF_Update_100HZ()`。
- 周期任务中每 `40ms` 调用一次 `crsf_send_50hz()`。

5. 接收逻辑说明
- `CRSF_Update_100HZ()` 每次从 `SCB2` 的 RX FIFO 中取走所有可读字节。
- 接收状态机按如下顺序解析：
- 等待同步地址 `0xC8`
- 读取长度字节
- 按长度收完整帧
- 校验 CRC8
- 当帧类型为 `0x16` 且负载长度匹配时，解析 RC 通道。
- 本实现当前只解析 RC 通道帧，不解析其他上行帧。

6. 通道数据说明
- `CRSF_CH[]` 保存 10 个原始通道值，范围为 `0~2047`。
- 遥控标准有效区间通常落在 `172~1810`。
- `CRSF_STD[]` 为标准化结果，按当前代码配置解释如下：
- 索引 `0`：Roll，输出范围 `-1000~1000`
- 索引 `1`：Pitch，输出范围 `-1000~1000`
- 索引 `2`：Throttle，输出范围 `-1000~1000`
- 索引 `3`：Yaw，输出范围 `-1000~1000`
- 索引 `4`：两段开关，输出 `0/1`
- 索引 `5`：三段开关，输出 `0/1/2`
- 索引 `6`：三段开关，输出 `0/1/2`
- 索引 `7`：两段开关，输出 `0/1`
- 索引 `8`：按钮，输出 `0/1`
- 索引 `9`：未使用，固定为 `0`

7. 失联处理
- 若当前时刻与 `CRSF_LAST_UPDATE_TIME` 的差值超过 `100000us`，则判定链路失联。
- 失联后：
- `CRSF_LINK_UP = 0`
- Roll、Pitch、Yaw 回到中位值
- 油门与各开关通道回到低位值
- 然后重新计算 `CRSF_STD[]`

8. 姿态回传说明
- `crsf_send_50hz()` 当前回传姿态类型帧 `0x1E`。
- 姿态数据来源于 `g_euler`。
- 角度单位换算为 `rad * 10000` 后发送。
- 当前代码实际发送顺序以实现为准：由 `g_euler.pitch`、`g_euler.roll`、`g_euler.yaw` 取值后写入回传帧。
- 若后续地面端显示的横滚或俯仰意义不一致，应优先检查该发送顺序与地面端解释方式。

9. 使用约束
- 接收机必须配置为 `CRSF` 协议，串口波特率必须为 `420000`。
- 当前实现假设接收机连接到 `UART4`，即单片机 `P14_0` 接接收机 TX，`P14_1` 供回传使用。
- 若只需要接收而不需要回传，TX 引脚可以悬空，但代码仍会按当前配置初始化 UART4 的 TX。

10. 调试建议
- 先确认 `CRSF_LINK_UP` 能稳定拉高。
- 再观察 `CRSF_CH[]` 是否随遥控拨杆变化。
- 最后检查 `CRSF_STD[]` 是否符合飞控期望的控制方向。
- 若完全收不到数据，优先检查：
- 接收机协议是否为 `CRSF`
- 接收机输出是否接到 `P14_0`
- 波特率是否为 `420000`
- 当前板级连线是否确实切换到 `UART4`

11. 备注
- 本说明以当前仓库中的 `crsf.c / crsf.h` 实现为准。
- 若后续修改了串口号、引脚、通道映射或回传内容，应同步更新本文件。
