## 机载落地建议

- 单看当前这份日志，最优得分仍倾向于进一步放宽 `innov_gate`，但联合两份实飞日志后，机载仍建议保持更稳妥的 `innov_gate=130 cm/s`。
- 当前机载参数保持为：`w_flow_v=4.5`、`w_acc_bias=0.003`、`innov_gate=130 cm/s`、`dead_max_s=0.20 s`、`w_res_v=1.0`。
- 当前机载参数相对旧机载参数回放结果：`flow_valid` 由约 91.63% 提升到约 99.70% ，最长连续失效由 3.652s 缩短到约 0.336s ，创新 RMS 由约 31.65 cm/s 降到约 22.32 cm/s，前向融合均值由约 -5.26 cm/s 收敛到约 -2.75 cm/s。
- 本轮数据下，SQUAL 与高度门控都不是主要问题，不建议优先调整 `SQUAL_HIGH/LOW` 或高度阈值；主要问题是创新门控过于容易把慢偏移放大成失效。
