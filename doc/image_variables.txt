Air image variables
===================

The only image result interface between CM7_1 and CM7_0 is:

    image_data[IMAGE_CAMERA_COUNT]

It is declared in `project/code/Image/image_data.h` and defined in shared memory by
`project/code/IPC/ipc_image_data.c`.

Camera slots:

    image_data[Front]   - front 2BL3 image board, received through Camera SPI
    image_data[Center]  - Air center/down MT9V03X, processed by image_down.c
    image_data[Back]    - rear 2BL3 image board, received through Camera SPI

Beacon data:

    image_data[camera].beacon_data[i].valid
    image_data[camera].beacon_data[i].x
    image_data[camera].beacon_data[i].y
    image_data[camera].beacon_data[i].area

Car-lamp data:

    image_data[camera].car_lamp_data[i].valid
    image_data[camera].car_lamp_data[i].cx
    image_data[camera].car_lamp_data[i].cy
    image_data[camera].car_lamp_data[i].width
    image_data[camera].car_lamp_data[i].length
    image_data[camera].car_lamp_data[i].angle

Coordinate convention:

    x/cx = raw_image_x - image_width / 2
    y/cy = raw_image_y - image_height / 2

For the center camera car lamp:

    cx < 0 means the airplane is left of the car.
    cx > 0 means the airplane is right of the car.
    cy < 0 means the airplane is behind the car.
    cy > 0 means the airplane is in front of the car.

`area` is connected-component area in pixels, not radius.

IPC shared addresses:

    image_data         0x28001000
    g_image_data_seq   0x28001160
    g_ipc_camera_spi_log 0x28001180

Old fusion/crop variables such as `g_image_fusion`, `g_air_mode2_*`,
`g_down_camera_lamp_*`, and `ipc_mode2_send()` are intentionally removed.
