# Pos_Est 单一水平速度估计器设计

## 目标

将当前旧互补速度估计器和V2影子估计器收敛为一套面向四旋翼水平速度闭环的估计器，
只修改`project/code/Estimation/Pos_Est/Pos_Est.c`，并保持以下外部接口不变：

- `Pos_Est_Init()`
- `Pos_Est_Reinit()`
- `Pos_Est_Update_1000HZ()`
- `Pos_Est_Update_50HZ()`
- `Pos_Est_vel_x`和`Pos_Est_vel_y`

最终公开速度仍为机体系左向为X正、前向为Y正，单位cm/s。

## 日志结论

两份46列实飞日志表明：

- 慢速正常可靠段中，旧算法相对光流和IMU代理滞后约95至100ms，V2输出约5至10ms。
- 慢速正常段代理残差中位数由旧算法约19.7cm/s下降到V2约6.7cm/s。
- 当前V2输出的1至10ms速度步进P99仍约19.2cm/s，不能直接作为速度环反馈。
- 当前正常更新约11.9%的速度修正超过20cm/s，P95达到25cm/s限幅。
- 慢速日志LC302飞行有效率约84%，极端日志约67%；最长飞行掉流约0.62s。
- 日志尾部I44存在约3.9%的传输损坏，因此最终遥测应减少通道。

当前输出跳变的主要确定性原因不是输出预测器架构错误，而是重复时间戳处理错误。
主循环追赶积压任务时可能在同一个`tick_1000us_cnt`下重复调用1000Hz更新。当前代码在
`dt <= 0`时清空pending correction，并继续向96项历史数组追加重复时间样本。日志中pending
持续时间中位数因此只有约2ms，而不是设计预期的数十毫秒。

## 最终架构

仅保留一套估计链：

```text
1000Hz IMU
  -> 机体系水平加速度预处理和静态bias扣除
  -> 四状态延迟KF历史传播
  -> pending correction输出预测器
  -> Pos_Est_vel_x/y

LC302新帧
  -> 20.8ms虚拟传感器时钟
  -> 延迟时刻LOS光流更新
  -> 历史状态回放至当前时刻
  -> 当前速度修正加入pending correction
```

KF状态保持为：左向速度、前向速度、左向残余加速度bias、前向残余加速度bias。
真实的高频运动由最新IMU直接传播到公开输出；光流修正只通过pending逐步注入。因此增加
pending时间常数不会给真实加速度响应增加同等延迟。

## 重复时间戳处理

`Pos_Est_Update_1000HZ()`仍可被外部重复调用，但V2核心只允许每个新时间戳传播一次：

- 当前时间戳等于最近历史时间戳：不追加history，不传播KF，不旋转或释放pending。
- 当前时间戳早于最近历史时间戳：保持状态并标记不可靠。
- 正常正时间差且不超过50ms：按实际`dt`传播。
- 时间差超过50ms：不把该间隔当成正常IMU积分；重建历史时基、清除pending并标记不可靠。

同一时间戳下公共IMU预处理可以按现有调度运行，但不得重复改变KF历史或公开速度。

## 参数策略

参数以慢速少拉扯日志为主目标，极端日志只作为数值稳定性和失效状态约束。

第一轮离线搜索范围：

```text
flow delay       36 / 40 / 44 ms
sigma_acc        30 / 40 / 50 cm/s^2/sqrt(Hz)
sigma_bias       0.2 cm/s^3/sqrt(Hz)
base sigma_flow  0.18 rad/s
output tau       60 / 80 / 100 ms
output accel     400 / 500 / 600 cm/s^2
```

初始推荐中心值为`sigma_acc=30`、`sigma_bias=0.2`、`sigma_flow=0.18`、`output tau=80ms`、
`output accel=500cm/s^2`。延迟不直接使用单日志最优值，而由两份日志交叉评分确定。

保留当前LOS几何、yaw机体系动力学、垂速补偿、动态观测噪声、NIS软缩放、硬拒绝、
重捕获一致性和bias冻结逻辑。正常修正上限和重捕获上限仅在离线回放证明有必要时降低，
不通过放宽门限追求表面上的低延迟。

## 删除范围

删除只服务旧互补估计器的代码和状态：

- `s_vel_pred_x/y`和旧50Hz互补校正。
- 旧`opflow_vel_x/y`速度LPF及其滤波器状态。
- 无外部消费者的level速度、位置积分及last状态。
- `Pos_Est_Update_1000HZ()`中只服务已注释遥测的flight mode、target和PID指针代码。
- V2影子命名和双套输出；内部函数改为单一估计器私有实现。

保留LC302读取、陀螺去旋转前端、水平加速度预处理、静态bias、KF历史、虚拟传感器时钟、
NIS、重捕获、pending和健康状态。

## 公开输出和失效行为

`Pos_Est_vel_x/y`直接发布当前时刻输出预测器结果，不发布内部延迟KF原始速度。

按用户批准，本阶段不修改速度环健康门控。光流长时间不可用时：

- 100至200ms设置degraded，继续IMU传播。
- 超过200ms设置unreliable，继续IMU惯性传播。
- 不自动切回旧估计器，不把速度强制设零，不在本文件内修改PID状态。

这是明确接受的剩余风险：现有速度环不会读取健康状态，长时间掉流时速度会随IMU bias漂移。
正常飞行优化通过后，健康门控应作为独立后续任务处理。

## 遥测

删除旧算法和重复V2诊断通道，保留分析单一估计器所需的最小字段：

- 水平加速度和静态bias。
- 三轴陀螺、pitch、roll、yaw、高度和垂速。
- LC302序号、有效位、原始积分和去旋转结果。
- 公开速度、内部KF速度、KF bias、创新、当前修正、NIS、状态和测量年龄。
- pending、动态sigma和距最近接受光流的时间。

不再发送I44/I45输出注入分量；它们可由pending差分离线重建，且当前日志中这两个尾部通道
存在传输损坏。遥测频率保持500Hz。

## 离线验证

主机回放必须复现真实调度，包括同一时间戳重复调用场景。每组参数同时回放慢速和极端日志。

正常慢速可靠段成功标准：

- 相对延迟不超过20ms。
- 1至10ms公开速度步进P99不超过6cm/s。
- 正常KF速度修正P95不超过20cm/s。
- yaw旋转双轴运动代理残差不高于当前V2。
- 无NaN、Inf、pending硬限幅或重复时间戳历史压缩。

极端日志只要求：

- 数值有界。
- 掉流时正确进入degraded和unreliable。
- 重捕获不让公开输出产生单帧大跳。
