0531 自稳模式六次试飞参数记录

目标:
用第一次飞行作为基线, 后续再连续飞 5 次不同参数, 之后统一比较 6 份日志, 找 Roll/Pitch 自稳模式角度环和角速度环的更优组合。

重要假设:
1. 第一次飞行使用的是当前代码默认参数。如果第一次飞行前通过 WiFi set 改过参数, 以实际 set 值为准。
2. 本文只覆盖自稳模式 Roll/Pitch 的角度环和角速度环参数。
3. Yaw、高度、位置、姿态解算和滤波参数本轮不改。
4. 当前代码中角度环 FF smoothing = 80 ms, angle output PT3 LPF = 50 Hz, angle output limit = +/-260 deg/s, 这几个是 fc_loop.c 里的 const, 不是 WiFi 参数。

BF 参考原则:
1. Betaflight FeedForward 是按 setpoint 变化率生成的前馈, 主要减少输入到响应的延迟; 太多 FF 可能在动作开始处造成 overshoot。
2. BF 文档建议做误差/相位分析时可以先把 FF 关掉, 这样更容易看 P/I/D 本身的作用。
3. P 提高会让跟随更紧, 过高会快速振荡; I 负责长期偏差和抗外力, 过高会慢振/拖; D 用来抑制过冲和增加阻尼, 但要小步增加并检查电机温度。
4. 对挂 GoPro/O3、电池较重的五寸/六寸机, 参数方向一般不是盲目加 FF, 而是内环 P/I 稍强、少量 D 阻尼、FF 适中或偏低。

遥测通道说明:
I0  = 自动时间戳
I1  = raw gyro x
I2  = raw gyro y
I3  = raw gyro z
I4  = raw acc x
I5  = raw acc y
I6  = raw acc z
I7  = filtered gyro x
I8  = filtered gyro y
I9  = filtered gyro z
I10 = filtered acc x
I11 = filtered acc y
I12 = filtered acc z
I13 = euler roll
I14 = euler pitch
I15 = roll angle target
I16 = roll angle measured
I17 = roll angle PID output, unit deg/s
I18 = roll angle PID P
I19 = roll angle PID I
I20 = roll angle PID D
I21 = roll angle PID error, unit deg
I22 = pitch angle target
I23 = pitch angle measured
I24 = pitch angle PID output, unit deg/s
I25 = pitch angle PID P
I26 = pitch angle PID I
I27 = pitch angle PID D
I28 = pitch angle PID error, unit deg
I29 = roll gyro target, unit deg/s
I30 = roll gyro measured filtered, unit deg/s
I31 = roll gyro PID output
I32 = roll gyro PID P
I33 = roll gyro PID I
I34 = roll gyro PID D
I35 = pitch gyro target, unit deg/s
I36 = pitch gyro measured filtered, unit deg/s
I37 = pitch gyro PID output
I38 = pitch gyro PID P
I39 = pitch gyro PID I
I40 = pitch gyro PID D

注意:
当前遥测没有单独发送 ff_term。因为 PID output = P + I + D + FF, 所以后续分析可用 output - P - I - D 反推出 FF。

后续 6 次日志分析时优先比较:
1. I21/I28 angle error 的 RMS、峰值和是否有持续偏置。
2. I29/I30、I35/I36 的目标角速度和实测角速度相位差。
3. I31/I37 output 与 P/I/D/反推 FF 的方向是否一致。
4. D 加入后 I34/I40 是否明显高频抖动, 电机是否发热。
5. FF 降低后 target 变化初段是否变钝, 以及 overshoot 是否下降。
