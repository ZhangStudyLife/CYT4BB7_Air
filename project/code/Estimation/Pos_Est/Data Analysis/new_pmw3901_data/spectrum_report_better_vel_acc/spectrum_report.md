## 结论

- 光流速度 I9/I10 的主要信息几乎全部落在 0~5Hz，95% 累积能量频率分别为 1.46Hz 和 3.17Hz。
- 水平线性加速度 I3/I4 的高频噪声主能量集中在 60~125Hz，且存在接近 100Hz 的稳定窄带峰，符合机体振动/电机谐波特征。
- 推荐将“有用运动带”定义为 0~15.0Hz，将 60Hz 以上视为主要噪声带。
- 推荐嵌入式水平加速度滤波器采用 `Notch@85.0Hz + LPF@15Hz`，用于在控制时延可接受的前提下压制高频窄带噪声。
