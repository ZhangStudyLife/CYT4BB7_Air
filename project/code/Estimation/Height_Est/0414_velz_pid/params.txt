## 四次飞行日志综合分析报告

---

### 一、四次飞行参数对比

| 飞行 | vel_kp | vel_ki | vel_kd | 核心变化 |
|------|--------|--------|--------|---------|
| #1 (0419) | **900** | 95 | 38 | 基线，高增益+有D |
| #2 (0435) | 400 | 120 | 0 | ⚠️ 数据格式异常（仅12列，可能是光流数据，非速度环PID） |
| #3 (0442) | **300** | **140** | 0 | 低增益+高积分 |
| #4 (0447) | **300** | **40** | 0 | 低增益+低积分 |

> **注意**: 第2次飞行(0435)的CSV只有12列，与其他3个(16列)不一致，可能不是同一套日志格式，以下对比主要基于#1/#3/#4。

---

### 二、关键指标对比（各自最佳悬停段）

| 指标 | #1 kp900/ki95/kd38 | #3 kp300/ki140/kd0 | #4 kp300/ki40/kd0 |
|------|-------|-------|-------|
| 悬停高度 | 1007mm | 803mm | 1093mm |
| **高度误差均值** | 7.6mm | 4.0mm(安静段) | 23.1mm → 收敛到~0 |
| **高度误差std** | 24.2mm(安静) / 67mm(全段) | **9.0mm(安静)** / 62mm(全段) | 59mm(全段) |
| 最大偏差 | 434mm | 395mm | 221mm |
| **滤波速度噪声** | **165mm/s** | **57mm/s(安静)** | 123mm/s |
| 油门波动范围 | **1339** (剧烈) | 579 | 474 |

| I项收敛时间 | 快(~15s) | 中等(~30s) | **极慢(~70s)** ⚠️ |

---

### 三、核心发现

#### 1. kp=900 造成严重的高频震荡（#1的根本问题）
- 4.3Hz震荡，油门波动范围1339，P项RMS=152
- 速度噪声165mm/s × kp=900 ≈ P项噪声148，与实测吻合
- **这就是之前"电机喘息声"和"跳跳虎"的根源**

#### 2. kp降到300后震荡大幅改善（#3/#4）
- 震荡频率降至0.3-2.6Hz，油门波动降低60%+
- 安静悬停时#3的高度std仅9mm，**精度相当好**
- 代价：阶跃响应变慢，但瓶颈在**pos_out限幅(0.25m/s)**而非kp

#### 3. ki=40太小，ki=140较合适（#3 vs #4）
- ki=40：积分时间常数τ=kp/ki=7.5s，实际收敛需70-80秒，前半程持续偏低23mm
- ki=140：τ=2.1s，约15秒收敛，后半段稳态误差仅3.4mm
- 两者的高度std几乎相同(59-62mm)，说明**ki主要影响稳态精度，不影响动态波动**

#### 4. D项(kd=0)缺失是隐患
- #1的kd=38虽然RMS仅占6%，但在大扰动恢复时提供阻尼
- #3/#4无D项，最大偏差时缺乏快速抑制能力
- 但在kp=300的低增益下，缺D的问题不如kp=900时突出

#### 5. 速度估计噪声是整条链路的瓶颈
- 原始速度噪声：446-920mm/s
- 滤波后仍有57-165mm/s
- **这是限制kp不能提高的根本原因**——kp越大，噪声放大越严重

#### 6. 操纵杆干扰段的识别
- 每次飞行中 |height_err|>50mm 占约30%时间，这些段对应pitch/roll操纵
- 安静段(无操纵)的定高精度远好于全段统计，说明**控制器本身工作正常，干扰主要来自姿态-高度耦合**

---

### 四、推荐参数方案

基于四次飞行的综合分析，建议下一次飞行使用：

```c
/* ===== Z 轴位置环参数 ===== */
params->pos_z_kp  = 0.8f;    // 保持不变
params->pos_z_ki  = 0.0f;
params->pos_z_kd  = 0.06f;
params->pos_z_kff = 0.0f;
params->pos_z_i_limit = 0.0f;
params->pos_z_d_lpf   = 2.0f;

/* ===== Z 轴速度环参数 ===== */
params->vel_z_kp  = 400.0f;   // 从300提到400，提高响应速度
params->vel_z_ki  = 100.0f;   // 折中：比40快收敛，比140稳定
params->vel_z_kd  = 15.0f;    // 加回少量D，抑制大扰动超调
params->vel_z_kff = 0.0f;
params->vel_z_i_limit = 450.0f;
params->vel_z_d_lpf   = 1.5f; // 略提高截止，让D项多一点作用
```

**理由**:
| 参数 | 值 | 为什么 |
|------|-----|--------|
| kp=400 | 比300提33% | #3证明300可以稳住，400在速度噪声123mm/s下P项抖动≈49(可接受) |
| ki=100 | τ=4s | 约20秒收敛，兼顾速度和稳定性 |
| kd=15 | 低D | 提供阻尼但不放大高频噪声，比原来的38保守 |

---

### 五、更根本的优化方向

**速度估计器优化**（收益远大于继续调PID）：
1. 增大 `TOF_VEL_WIN` 从5帧到7-8帧 → 差分基线从40ms增到60-70ms，速度噪声降低30-40%
2. 提高慢速IIR的 `TOF_VEL_POS_ALPHA` 从0.20到0.12-0.15 → 更平滑但延迟增加10-15ms
3. 长远考虑：互补滤波融合TOF差分速度与加速度计积分，可大幅改善速度估计的信噪比
