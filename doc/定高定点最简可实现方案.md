# 定高定点最简可实现方案（仅用你当前已有变量）

## 1. 目标与边界

### 1.1 目标

- 场景：家庭室内、无 GPS、弱光。
- 高度：稳定在 `1.0m ~ 1.5m`。
- 能力：实现可持续定高 + 定点（短时稳定优先）。

### 1.2 已有输入（你当前明确有）

- `gx, gy, gz`：ICM42688 角速度（`deg/s`）
- `ax, ay, az`：ICM42688 加速度原始值（未标定）
- `flow_dx, flow_dy`：PMW3901 原始光流增量（每帧像素）
- `h_mm`：你已融合好的高度（单位 `mm`，来自 TOF+气压融合链路）

### 1.3 已知扰动与风险

- 地面电缆供电导致持续外力拉扯（低频偏置扰动）
- TOF 偶发遮挡（高度瞬时异常）
- 弱光导致光流噪声、跳变、失效概率提升

---

## 2. 坐标与极性（严格按你给定规范）

### 2.1 机体系（FRD）

- `+X` 前
- `+Y` 右
- `+Z` 下

### 2.2 姿态/角速度/加速度极性

- `roll > 0`：右倾
- `pitch > 0`：抬头
- `yaw > 0`：俯视顺时针
- `gx > 0`：右滚
- `gy > 0`：抬头
- `gz > 0`：俯视顺时针
- 加计静止平放：`ax≈0, ay≈0, az≈-1g`

### 2.3 光流极性

- 向右水平移动：`Δx > 0`
- 向前水平移动：`Δy > 0`

### 2.4 本文位置坐标定义（你已选）

- 使用 **纯光流积分坐标**：
  - `pos_x`：由光流“前向分量”积分得到
  - `pos_y`：由光流“右向分量”积分得到
- 不做磁航向全局旋转对齐（无磁力计前提下最简且最稳）

---

## 3. 最小实现架构（双频循环）

### 3.1 频率建议

- 快环（`250Hz`，`dt_fast=0.004s`）：
  - 姿态更新（gyro+acc）
  - IMU 预测（`vx, vy, x, y`）
- 慢环（`100Hz`，`dt_flow=0.01s`）：
  - 光流处理（像素->位移/速度）
  - 融合校正（创新修正）
  - 定点控制（位置环/速度环）

### 3.2 为什么这样分

- 光流天然低频，IMU 天然高频。
- 高速姿态/预测 + 低速观测校正，能在弱光下保持更平顺。

---

## 4. 输入标准化（必须先做）

## 4.1 单位转换

- 角速度转弧度：
  - `wx = gx * DEG2RAD`
  - `wy = gy * DEG2RAD`
  - `wz = gz * DEG2RAD`
- 高度转米：
  - `h_raw_m = h_mm * 0.001`
- 加速度（若驱动已输出 g）：
  - `a_mps2 = a_g * 9.80665`
- 加速度（若是原始计数）：
  - `a_g = (raw - bias0) / acc_lsb_per_g`
  - 然后乘 `9.80665`

> 说明：加计未标定并不阻止实现。本文用“在线偏置自适应”补偿水平轴偏差（`b_ax, b_ay`）。

### 4.2 高度抗突变（应对 TOF 偶发遮挡）

- 输入虽是融合高度，仍建议再做一次“限速平滑”：
  - `dh = clamp(h_raw_m - h_filt_m, -H_RATE_LIM*dt, +H_RATE_LIM*dt)`
  - `h_filt_m += dh`

推荐初值：

- `H_RATE_LIM = 1.5 m/s`
- `h_filt_m` 限幅在 `[0.08, 2.5]`

---

## 5. 姿态解算（最简可执行版）

目标：只要 `roll/pitch` 稳，XY 融合就能用；不依赖磁力计。

### 5.1 状态

- 四元数：`q = [qw, qx, qy, qz]`
- 陀螺零偏：`b_gx, b_gy, b_gz`
- 积分项：`ei_x, ei_y, ei_z`

### 5.2 算法核心（Mahony 最简变体）

1. `a = normalize([ax, ay, az])`
2. 用当前 `q` 计算估计重力方向 `g_est_body`
3. 误差 `e = a × g_est_body`
4. `w_corr = w_meas - b_g + Kp_att*e + Ki_att*ei`
5. 用 `w_corr` 积分四元数，归一化
6. 从 `q` 得 `roll, pitch`

推荐初值：

- `Kp_att = 0.35`
- `Ki_att = 0.003`

---

## 6. 光流从像素到速度/位移（可直接写代码）

## 6.1 映射关系（按你的极性）

- `flow_dy > 0` 对应前向运动（`+X`）
- `flow_dx > 0` 对应右向运动（`+Y`）

因此：

- `pix_x = flow_dy`
- `pix_y = flow_dx`

### 6.2 倾角补偿（必须显式）

- `pix_x_corr = pix_x + K_tilt_x * tan(pitch)`
- `pix_y_corr = pix_y + K_tilt_y * tan(roll)`

推荐初值：

- `K_tilt_x = 480`
- `K_tilt_y = 480`

### 6.3 高度缩放（像素 -> 米）

- 在 `1m` 高度下，定义标定系数 `K_PIX_TO_M_AT_1M`
- 当前帧尺度：
  - `k = K_PIX_TO_M_AT_1M * h_filt_m`

位移增量：

- `dpos_x_flow = pix_x_corr * k`
- `dpos_y_flow = pix_y_corr * k`

速度观测：

- `v_x_flow = dpos_x_flow / dt_flow`
- `v_y_flow = dpos_y_flow / dt_flow`

### 6.4 观测滤波和限幅

- 一阶低通：
  - `v_x_meas += alpha_flow*(v_x_flow - v_x_meas)`
  - `v_y_meas += alpha_flow*(v_y_flow - v_y_meas)`
- 限幅：
  - `v_x_meas = clamp(v_x_meas, -V_FLOW_MAX, +V_FLOW_MAX)`
  - `v_y_meas = clamp(v_y_meas, -V_FLOW_MAX, +V_FLOW_MAX)`

推荐初值：

- `alpha_flow = 0.2`
- `V_FLOW_MAX = 1.5 m/s`

---

## 7. XY 融合器（关键：如何“从现有变量得到位置”）

这里采用最简“预测-校正”结构：

- IMU 给短时预测（连续、抗丢帧）
- 光流给观测校正（抑制漂移）

### 7.1 状态变量

- `x, y`（m）
- `vx, vy`（m/s）
- `b_ax, b_ay`（m/s²，水平加计慢偏置）
- `pos_flow_x, pos_flow_y`（m，光流积分轨迹）

### 7.2 IMU 预测（快环 250Hz）

1. 将机体系加速度转到水平积分坐标
2. 去重力（通过姿态矩阵处理后仅取水平分量）
3. 去慢偏置：
   - `ax_use = ax_world - b_ax`
   - `ay_use = ay_world - b_ay`
4. 速度积分：
   - `vx += ax_use * dt_fast`
   - `vy += ay_use * dt_fast`
5. 位置积分：
   - `x += vx * dt_fast`
   - `y += vy * dt_fast`

### 7.3 光流校正（慢环 100Hz）

1. 光流位置积分：
   - `pos_flow_x += dpos_x_flow`
   - `pos_flow_y += dpos_y_flow`
2. 创新（残差）：
   - 速度残差：`evx = v_x_meas - vx`, `evy = v_y_meas - vy`
   - 位置残差：`epx = pos_flow_x - x`, `epy = pos_flow_y - y`
3. 融合修正：
   - `vx += W_v * evx`
   - `vy += W_v * evy`
   - `x  += W_p * epx`
   - `y  += W_p * epy`
4. 偏置在线自适应（解决未标定加计）：
   - `b_ax += K_b * evx * dt_flow`
   - `b_ay += K_b * evy * dt_flow`

推荐初值：

- `W_v = 0.35`
- `W_p = 0.12`
- `K_b = 0.02`

---

## 8. 光流可用性判定与退化策略

你说弱光明显，必须有退化逻辑，否则定点会“抽风”。

### 8.1 观测有效条件（最简）

同时满足以下条件才 `flow_valid=true`：

- `h_filt_m` 在 `[0.08, 2.0]`
- `abs(flow_dx) < PIX_MAX` 且 `abs(flow_dy) < PIX_MAX`
- `abs(evx) < V_INNOV_GATE` 且 `abs(evy) < V_INNOV_GATE`

推荐初值：

- `PIX_MAX = 100`
- `V_INNOV_GATE = 1.8 m/s`

### 8.2 无效时怎么做

- 暂停第 7.3 的光流修正（只保留 IMU 预测）
- 启动短时外推计时器 `t_dead`
- 若 `t_dead > T_DEAD_MAX`：
  - 对 `vx, vy` 施加指数衰减（避免无限飘）
  - 定点控制从“位置保持”退化为“速度阻尼”

推荐初值：

- `T_DEAD_MAX = 0.3s`

---

## 9. 定高定点控制（最简闭环）

> 你的重点是位置融合；这里给最小可落地控制接口，便于立刻闭环飞。

### 9.1 模式逻辑

- 摇杆有量（超过死区）：`mode_xy = VELOCITY`
- 摇杆回中持续 `T_LOCK`：`mode_xy = POSITION_HOLD`，锁定当前 `x,y`

推荐：

- `T_LOCK = 0.6s`

### 9.2 控制级联

1. 位置环（仅在 `POSITION_HOLD`）`vx_sp = PID_x(x_sp - x)``vy_sp = PID_y(y_sp - y)`
2. 速度环`pitch_sp = PID_vx(vx_sp - vx)``roll_sp  = PID_vy(vy_sp - vy)`
3. 高度环（直接用你已融合 `h_mm`）
   `z = h_filt_m`
   `vz_sp = PID_z(z_sp - z)`
   `thrust = THR_BASE + PID_vz(vz_sp - vz_est)`

### 9.3 外力抗扰（地线拉扯）

- 速度环积分限幅必须开
- `b_ax,b_ay` 在线修正必须开
- 否则稳态会长期偏移

---

## 10. 一次性标定（必须做，且非常短）

## 10.1 标定 `K_PIX_TO_M_AT_1M`

步骤：

1. 高度保持在 `1.00m`（`h_filt_m≈1.0`）
2. 人工沿机体前向平移已知距离 `D`（建议 `D=1.0m`）
3. 记录期间累计 `sum_pix_x_corr`
4. 计算：
   - `K_PIX_TO_M_AT_1M = D / sum_pix_x_corr`
5. 右向重复一次，若差异大，取均值

## 10.2 快速符号自检

- 前推机体：`pos_x` 应增加
- 右推机体：`pos_y` 应增加
- 若相反，仅翻对应符号（`pix_x` 或 `pix_y` 前乘 `-1`）

---

## 11. 完整最简伪代码（可直接改成 C）

```c
// ===================== 参数 =====================
const float DT_FAST = 0.004f;     // 250Hz
const float DT_FLOW = 0.010f;     // 100Hz

const float DEG2RAD = 0.0174532925f;
const float G0 = 9.80665f;

const float KP_ATT = 0.35f;
const float KI_ATT = 0.003f;

const float K_TILT_X = 480.0f;
const float K_TILT_Y = 480.0f;
float K_PIX_TO_M_AT_1M = 0.00210f; // 需按第10节标定

const float FLOW_ALPHA = 0.20f;
const float V_FLOW_MAX = 1.5f;
const float PIX_MAX = 100.0f;
const float V_INNOV_GATE = 1.8f;

const float W_V = 0.35f;
const float W_P = 0.12f;
const float K_B = 0.02f;
const float T_DEAD_MAX = 0.30f;

const float H_RATE_LIM = 1.5f;
const float H_MIN = 0.08f;
const float H_MAX = 2.5f;

// ===================== 状态 =====================
typedef struct {
  // attitude
  float qw, qx, qy, qz;
  float bgx, bgy, bgz;
  float eix, eiy, eiz;
  float roll, pitch; // rad

  // height
  float h_filt_m;

  // flow obs
  float vx_meas, vy_meas;
  float pos_flow_x, pos_flow_y;

  // fused XY
  float x, y;
  float vx, vy;
  float bax, bay;

  // health
  int flow_invalid_cnt;
  float t_dead;
} EstState;

EstState S;

// ===================== 工具函数 =====================
float clampf(float v, float lo, float hi) {
  if (v < lo) return lo;
  if (v > hi) return hi;
  return v;
}

void normalize3(float* x, float* y, float* z) {
  float n = sqrtf((*x)*(*x) + (*y)*(*y) + (*z)*(*z));
  if (n > 1e-6f) { *x /= n; *y /= n; *z /= n; }
}

// 由四元数得到机体系重力方向估计
void gravity_from_q(float qw, float qx, float qy, float qz, float* gx, float* gy, float* gz) {
  *gx = 2.0f * (qx*qz - qw*qy);
  *gy = 2.0f * (qw*qx + qy*qz);
  *gz = qw*qw - qx*qx - qy*qy + qz*qz;
}

void q_normalize(float* qw, float* qx, float* qy, float* qz) {
  float n = sqrtf((*qw)*(*qw)+(*qx)*(*qx)+(*qy)*(*qy)+(*qz)*(*qz));
  if (n > 1e-6f) { *qw/=n; *qx/=n; *qy/=n; *qz/=n; }
}

// ===================== 快环：姿态 + 预测 =====================
void update_fast_250hz(float gx_dps, float gy_dps, float gz_dps,
                       float ax_g, float ay_g, float az_g,
                       float h_mm) {

  // 1) 高度限速滤波
  float h_raw = h_mm * 0.001f;
  float dh = clampf(h_raw - S.h_filt_m, -H_RATE_LIM*DT_FAST, H_RATE_LIM*DT_FAST);
  S.h_filt_m = clampf(S.h_filt_m + dh, H_MIN, H_MAX);

  // 2) gyro -> rad/s
  float wx = gx_dps * DEG2RAD;
  float wy = gy_dps * DEG2RAD;
  float wz = gz_dps * DEG2RAD;

  // 3) acc normalize
  float ax = ax_g, ay = ay_g, az = az_g;
  normalize3(&ax, &ay, &az);

  // 4) Mahony校正
  float gx_est, gy_est, gz_est;
  gravity_from_q(S.qw, S.qx, S.qy, S.qz, &gx_est, &gy_est, &gz_est);

  // e = a x g_est
  float ex = ay*gz_est - az*gy_est;
  float ey = az*gx_est - ax*gz_est;
  float ez = ax*gy_est - ay*gx_est;

  S.eix += ex * DT_FAST;
  S.eiy += ey * DT_FAST;
  S.eiz += ez * DT_FAST;

  wx = wx - S.bgx + KP_ATT*ex + KI_ATT*S.eix;
  wy = wy - S.bgy + KP_ATT*ey + KI_ATT*S.eiy;
  wz = wz - S.bgz + KP_ATT*ez + KI_ATT*S.eiz;

  // 5) 四元数积分
  float qw = S.qw, qx = S.qx, qy = S.qy, qz = S.qz;
  float halfdt = 0.5f * DT_FAST;
  S.qw += (-qx*wx - qy*wy - qz*wz) * halfdt;
  S.qx += ( qw*wx + qy*wz - qz*wy) * halfdt;
  S.qy += ( qw*wy - qx*wz + qz*wx) * halfdt;
  S.qz += ( qw*wz + qx*wy - qy*wx) * halfdt;
  q_normalize(&S.qw, &S.qx, &S.qy, &S.qz);

  // 6) roll/pitch (rad)
  S.roll  = atan2f(2.0f*(S.qw*S.qx + S.qy*S.qz), 1.0f - 2.0f*(S.qx*S.qx + S.qy*S.qy));
  S.pitch = asinf(clampf(2.0f*(S.qw*S.qy - S.qz*S.qx), -1.0f, 1.0f));

  // 7) 机体系加速度 -> 水平积分坐标（纯光流积分坐标，不做yaw全局旋转）
  // 先转 m/s^2
  float abx = ax_g * G0;
  float aby = ay_g * G0;
  float abz = az_g * G0;

  // 只用 roll/pitch 一阶近似去重力并得水平加速度
  // 小角度时可工作；家庭悬停通常倾角不大
  float ax_world = abx + G0 * S.pitch; // 前向
  float ay_world = aby - G0 * S.roll;  // 右向

  // 8) IMU预测
  float ax_use = ax_world - S.bax;
  float ay_use = ay_world - S.bay;

  S.vx += ax_use * DT_FAST;
  S.vy += ay_use * DT_FAST;
  S.x  += S.vx * DT_FAST;
  S.y  += S.vy * DT_FAST;
}

// ===================== 慢环：光流观测 + 校正 =====================
void update_flow_100hz(float flow_dx, float flow_dy) {
  // 1) 像素映射（按极性：dy->前向x，dx->右向y）
  float pix_x = flow_dy;
  float pix_y = flow_dx;

  // 2) 倾角补偿
  float pix_x_corr = pix_x + K_TILT_X * tanf(S.pitch);
  float pix_y_corr = pix_y + K_TILT_Y * tanf(S.roll);

  // 3) 尺度（1m标定系数 * 当前高度）
  float k = K_PIX_TO_M_AT_1M * S.h_filt_m;
  float dpos_x = pix_x_corr * k;
  float dpos_y = pix_y_corr * k;
  float vx_flow = dpos_x / DT_FLOW;
  float vy_flow = dpos_y / DT_FLOW;

  // 4) 低通 + 限幅
  S.vx_meas += FLOW_ALPHA * (vx_flow - S.vx_meas);
  S.vy_meas += FLOW_ALPHA * (vy_flow - S.vy_meas);
  S.vx_meas = clampf(S.vx_meas, -V_FLOW_MAX, V_FLOW_MAX);
  S.vy_meas = clampf(S.vy_meas, -V_FLOW_MAX, V_FLOW_MAX);

  // 5) 有效性判定
  bool pix_ok = (fabsf(flow_dx) < PIX_MAX) && (fabsf(flow_dy) < PIX_MAX);
  bool h_ok = (S.h_filt_m >= 0.08f && S.h_filt_m <= 2.0f);
  float evx0 = S.vx_meas - S.vx;
  float evy0 = S.vy_meas - S.vy;
  bool innov_ok = (fabsf(evx0) < V_INNOV_GATE) && (fabsf(evy0) < V_INNOV_GATE);
  bool flow_valid = pix_ok && h_ok && innov_ok;

  if (flow_valid) {
    S.t_dead = 0.0f;
    S.flow_invalid_cnt = 0;

    // 6) 光流位置积分
    S.pos_flow_x += dpos_x;
    S.pos_flow_y += dpos_y;

    // 7) 融合校正
    float evx = S.vx_meas - S.vx;
    float evy = S.vy_meas - S.vy;
    float epx = S.pos_flow_x - S.x;
    float epy = S.pos_flow_y - S.y;

    S.vx += W_V * evx;
    S.vy += W_V * evy;
    S.x  += W_P * epx;
    S.y  += W_P * epy;

    // 8) 在线偏置修正（关键：加计未标定仍可收敛）
    S.bax += K_B * evx * DT_FLOW;
    S.bay += K_B * evy * DT_FLOW;
  } else {
    // 退化：只保留短时惯导
    S.flow_invalid_cnt++;
    S.t_dead += DT_FLOW;

    if (S.t_dead > T_DEAD_MAX) {
      // 防止无限漂移：速度阻尼
      S.vx *= 0.98f;
      S.vy *= 0.98f;
    }
  }
}
```

## 12. 参数调试顺序（必须按顺序）

1. 先只开姿态，不开位置环目标：`roll/pitch` 平稳，无高频抖动
2. 开光流换算，不开融合修正目标：推动机体时 `v_x_meas/v_y_meas` 方向正确
3. 开融合修正（`W_v`、`W_p`）目标：悬停漂移明显下降
4. 开偏置自适应（`K_b`）目标：电缆外力下稳态偏移减小
5. 最后调位置/速度 PID
   目标：不振荡、回中快、超调小

## 13. 验收标准（可量化）

### 13.1 1.0m 悬停 60s

- 水平漂移半径：`<= 0.25m`（弱光可放宽到 `0.35m`）
- 高度波动（峰峰）：`<= 0.20m`

### 13.2 1.5m 悬停 60s

- 水平漂移半径：`<= 0.35m`
- 高度波动（峰峰）：`<= 0.25m`

### 13.3 干扰恢复

- 手推后释放：`3~5s` 回到 `0.2m` 半径内

### 13.4 TOF 偶发遮挡

- 不出现瞬时高度尖峰导致的猛拉杆行为
- 遮挡解除后 `2s` 内恢复稳定

## 14. 你可以直接拿来用的最小输出接口

每周期对外输出：

- `x, y`（m）：融合后位置
- `vx, vy`（m/s）：融合后速度
- `h_filt_m`（m）：稳健高度
- `flow_valid`：光流可用性
- `bax, bay`：在线估计偏置（用于监控是否收敛）

这组量已经足够支持室内无 GPS 的定高定点闭环。
