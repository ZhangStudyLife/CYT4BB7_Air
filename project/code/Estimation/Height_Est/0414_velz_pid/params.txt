### 三、核心发现

#### 1. kp=900 造成严重的高频震荡（#1的根本问题）
- 4.3Hz震荡，油门波动范围1339，P项RMS=152
- 速度噪声165mm/s × kp=900 ≈ P项噪声148，与实测吻合
- **这就是之前"电机喘息声"和"跳跳虎"的根源**

#### 2. kp降到300后震荡大幅改善（#3/#4）
- 震荡频率降至0.3-2.6Hz，油门波动降低60%+
- 安静悬停时#3的高度std仅9mm，**精度相当好**
- 代价：阶跃响应变慢，但瓶颈在**pos_out限幅(0.25m/s)**而非kp

#### 3. ki=40太小，ki=140较合适（#3 vs #4）
- ki=40：积分时间常数τ=kp/ki=7.5s，实际收敛需70-80秒，前半程持续偏低23mm
- ki=140：τ=2.1s，约15秒收敛，后半段稳态误差仅3.4mm
- 两者的高度std几乎相同(59-62mm)，说明**ki主要影响稳态精度，不影响动态波动**

#### 4. D项(kd=0)缺失是隐患
- #1的kd=38虽然RMS仅占6%，但在大扰动恢复时提供阻尼
- #3/#4无D项，最大偏差时缺乏快速抑制能力
- 但在kp=300的低增益下，缺D的问题不如kp=900时突出

#### 5. 速度估计噪声是整条链路的瓶颈
- 原始速度噪声：446-920mm/s
- 滤波后仍有57-165mm/s
- **这是限制kp不能提高的根本原因**——kp越大，噪声放大越严重

#### 6. 操纵杆干扰段的识别
- 每次飞行中 |height_err|>50mm 占约30%时间，这些段对应pitch/roll操纵
- 安静段(无操纵)的定高精度远好于全段统计，说明**控制器本身工作正常，干扰主要来自姿态-高度耦合**

---

### 四、推荐参数方案

基于四次飞行的综合分析，建议下一次飞行使用：

### 五、更根本的优化方向

**速度估计器优化**（收益远大于继续调PID）：
1. 增大 `TOF_VEL_WIN` 从5帧到7-8帧 → 差分基线从40ms增到60-70ms，速度噪声降低30-40%
2. 提高慢速IIR的 `TOF_VEL_POS_ALPHA` 从0.20到0.12-0.15 → 更平滑但延迟增加10-15ms
3. 长远考虑：互补滤波融合TOF差分速度与加速度计积分，可大幅改善速度估计的信噪比

**问题的本质**：位置环只有比例+微分响应（无前馈），而目标以350mm/s爬升。

1. **加速阶段(t=0~0.5s)**：位置误差+42mm → pos_out=+31mm/s，但飞行器惯性小、推力大，vz迅速飙到576mm/s（是目标斜坡率350的1.65倍！）

2. **过冲斜坡阶段(t=0.5~2.5s)**：飞机持续领先目标40-60mm，pos_out一直是负的(-30~-70mm/s)在制动，但速度始终高于350mm/s。**位置环在整个斜坡阶段都在刹车，却刹不住**。

3. **斜坡结束瞬间(t=2.5s)**：目标从350mm/s突然变0mm/s（斜坡到头了），但飞机还有318mm/s的速度。**位置环此时看到err≈0，几乎不输出制动命令**——它不知道vz=318mm/s马上要造成巨大超调。

4. **位置环D-term太弱**：pos_z_kd=0.06，产生的制动信号 = -0.06 × 0.318 = **-0.019m/s**（仅19mm/s），面对318mm/s的残余速度杯水车薪。

#### 这是**位置环**的问题，不是速度环

速度环(kp=350/kd=35/d_lpf=5Hz)在这次飞行中工作得相当好——在穿越点(t=2.7s)：
- vel_err = -329mm/s → P = 350 × -0.329 = **-115**
- I = **-66**
- D = 正在工作

速度环确实在用力刹车(vel_out=-157)，但**位置环给它的目标(pos_out)太小了**。pos_out = -11mm/s，而实际需要的是 -318mm/s 才能让飞机立刻停下来。


### 五、具体改进建议

#### 优先级P0：位置环增加前馈（kff）—— 消除起飞超调

当前代码中 `pos_z_kff = 0`，PID_Update已经支持前馈计算。只需修改参数：

```c
params->pos_z_kff = 1.0f;  // 前馈增益=1.0，直接将目标速率作为速度指令
```

**效果**：
- 斜坡爬升时：pos_out = kp×err + kd×d_meas + **1.0 × 0.35** = 位置修正 + **350mm/s前馈**
- 速度环收到350mm/s目标，自动调节油门维持该速度
- 斜坡结束时：前馈瞬间归零，pos_out只剩位置修正项，不再有"惯性"
- 不需要额外代码修改，仅改一个参数

#### 优先级P0：降低斜坡率 350→250mm/s

350mm/s接近pos_out限幅(±250mm/s)的极限，留给位置修正的余量太小：

```c
#define FC_TARGET_H_RAMP_UP_MPS   0.25f   /* 从0.35降到0.25 */
#define FC_TARGET_H_RAMP_DOWN_MPS 0.25f   /* 从0.30降到0.25 */
```

#### 优先级P1：提高位置环D增益

```c
params->pos_z_kd = 0.15f;   // 从0.06提到0.15
params->pos_z_d_lpf = 3.0f; // 从2.0提到3.0
```

pos_z_kd=0.15时，在318mm/s残余速度下产生 -0.15×0.318 = **-48mm/s** 的制动命令（vs现在的-19mm/s）。

#### 优先级P2：稳态改善——速度估计器进一步平滑

当前vz_filt的46mm/s RMS噪声通过kp=350放大为16的P-term噪声，这是2.83Hz振荡的来源。可以考虑：
- 将 `TOF_FUSED_VZ_HIST_LEN` 从7帧增到9帧（差分基线80ms），速度噪声再降20%
- 或者在控制器侧对vz额外加一级一阶LPF（但会增加延迟）
